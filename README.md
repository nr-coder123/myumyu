# 武林乾坤全圖 · Murim Realm Map Studio

An interactive cartographic studio and territorial map builder for Martial Arts (Murim / Wuxia) fantasy realms.

---

## 🚀 Quick Start Instructions

You can start the application locally on Windows, macOS, or Linux using any of the included launchers:

### Option 1: Using Windows Batch Script (`.bat`)
Simply double-click or run from Command Prompt:
```cmd
start.bat
```
or
```cmd
run.bat
```

### Option 2: Using Python Script (`.py`)
Run cross-platform on Windows, macOS, or Linux:
```bash
python start.py
```
or
```bash
python run.py
```

### Option 3: Standard npm commands
If you prefer standard terminal commands:
```bash
npm install
npm run dev
```

---

## ⚙️ Features
- **Node.js Auto-Check**: The batch and python launchers automatically verify that Node.js is installed.
- **Auto Dependency Installation**: Automatically runs `npm install` on first launch if `node_modules` is missing.
- **Auto Browser Opening**: Automatically opens your default web browser to `http://localhost:3000`.
- **Full Factory Reset Support**: Built-in reset options in the UI to clear browser storage (`localStorage`) and restore default maps anytime.
